The Engineering Friction

The 450ms Virtual DOM Freezing Dilemma

Shell Oman required continuous real-time hazard detection across 16 camera streams. When each frame received automated YOLOv11 bounding boxes and telemetry bounding coordinates from WebSockets at 30 FPS, React attempted to perform reconciliation for 480 node mutations every single second. The main execution thread seized up, garbage collection thrashing spiked, and the browser tab routinely froze for up to 450ms.

The Architectural Solution

Bypassing the DOM with Dedicated OffscreenCanvas

I severed the video and coordinate rendering pipeline entirely from React's component tree. Incoming WebSocket payloads were routed to a dedicated Web Worker via transferable ArrayBuffers. The worker directly controlled an OffscreenCanvas, blitting bounding coordinates straight to WebGL/Canvas2D buffers without a single React re-render.

Friction Point

The 21-Day Appraisal Logjam

Appraisals were conducted on hundreds of fragmented Microsoft Excel workbooks circulated via email threads. Formulas were routinely accidentally overwritten, reviewers overwrote peer evaluation columns, and finance spent three weeks manually untangling discrepancies before monthly payroll could execute.

Architectural Intervention

Deterministic Client-Side AST Engine

I architected an in-browser formula lexer that evaluates dynamic performance curves and bonus algorithms in real-time as managers slide metrics. Paired with normalized Redux slice state machines and strict RBAC field masking, managers obtain instantaneous feedback with an immutable revision log.

The Field Reality

Handling Network Turbulence at 40,000 Concurrent Sessions

In tier-2/3 universities, cellular bandwidth regularly drops completely during exam surges. Traditional web apps crashed, wiping student answers and forcing re-examinations. By deploying an offline-first architecture powered by IndexedDB and in-memory WebCrypto encryption, the student's entire exam environment continues seamlessly regardless of network presence, syncing deterministically when packets resume.
