How I think about building for the web.

“I care less about how a page looks when everything works, and more about how it behaves when things go wrong: a slow network, a late-loading font, or someone navigating solely with a keyboard.”

Craft Manifesto · Praveen Kumar S.
01

Polished, but lightweight

Minimal CSS weight, zero unnecessary runtime abstractions, native browser layout primitives, and hardware-accelerated 60fps animations that never drop a frame.

Metric
0ms jank target
02

Clear, predictable state

Deterministic finite state patterns. Async data flows decoupled from presentation components, making bugs reproducible and client state predictable under jitter.

Axiom
Immutable store
03

Built for everyone, everywhere

WCAG AA accessibility from day zero. Logical focus rings, semantic landmarks, high-contrast resilience, and screen-reader navigable telemetry feeds.
